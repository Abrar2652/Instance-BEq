# Instance-BEq — Formal Faithfulness Certification for Structure-to-Instance Autoformalization

Autoformalizers that specialize an abstract formal theory to a concrete problem produce Lean 4
`def`s, typeclass `instance`s, and instantiated theorems. A file can **type-check while being
unfaithful**: a `def` encodes the wrong objective, an `instance` discharges a structural condition
with `sorry` (a *hollow* instance — `sorry` is only a warning), or a theorem states the wrong claim.
**Instance-BEq** is a formal, symbolic-equivalence certifier that operates *below* the theorem-
statement level, where no prior faithfulness work (BEq, BEq+, ReForm, RAutoformalizer) reaches.

## The three checks

1. **Definitional faithfulness** — prove `D_gen = D_ref` against an independent reference via a Lean
   tactic ensemble (`rfl`/`simp`/`ring`/`unfold;ring`). Kernel-sound ⇒ a proved equality is genuine
   (**precision 1**); a sound certifier emits `{faithful, abstain}`.
2. **Instance soundness (headline)** — walk the **transitive axiom closure** of the instance with
   `#print axioms` and require it to be `sorry`-free and within `{propext, Classical.choice,
   Quot.sound}`. This is **decidable**, hence an exact certificate. Scoped to the instance's
   condition fields (template lemmas are `sorry`-bodied by design).
3. **Theorem transfer** — (3a) compile the canonical `apply`-specialization proof; (3b) back-
   translate the statement and compare to the informal claim (the one LLM-assisted step, reported
   separately with calibration).

Formal certificate = **1 ∧ 2 ∧ 3a** (all Lean-kernel-grounded); 3b is the informal bridge.

## Key results (all regenerable; see below)

- **2 of 6** gold structure families released with the base system carry **hollow** instances
  (ADMM, BCD) — they type-check yet certify nothing.
- On controlled fault injection, instance-soundness is **exact** (P = R = F1 = 1.0) where
  type-check-only has recall 0.
- Against four baselines (type-check-only, BEq+, LLM-judge, majority-vote) on a 57-item human-
  labelled benchmark, Instance-BEq has the **highest overall F1 (0.97, 95% CI [0.88, 1.00])** and
  the **fewest false certifications (1 vs 3–23)**, and is the only method that addresses the
  instance-soundness and transfer-validity checks at all.

## Reproduce the paper

Every number in the paper is regenerated by a script in `scripts/`; outputs land in `eval_logs/*.json`,
and the LaTeX tables/figures are built from those JSONs.

**(a) Symbolic results — need Lean, no GPU/API.** The vendored Lean project (`Code/lean/`, Optlib +
the autoformalization examples, Apache-2.0 — see `THIRD_PARTY.md`) builds against the pinned Mathlib
`v4.13.0`. Build it once (`cd Code/lean && lake exe cache get && lake build`; the multi-GB Mathlib
cache is fetched, not shipped), then from the repo root:

```bash
python scripts/certify_gold.py          # 2/6 gold families hollow            (tab:gold)
python scripts/fault_injection.py       # check-2 P=R=F1=1.0, type-check R=0  (tab:faults)
python scripts/certifier_all_checks.py  # certifier on all four checks vs gold
python scripts/ref_source_ablation.py   # reference-source ablation           (tab:refabl)
python scripts/tactic_size_sweep.py     # tactic-ensemble size ablation       (tab:tacticsize)
python scripts/synthetic_stress.py      # 71-item synthetic soundness bench   (tab:synthetic)
```

**(b) LLM-assisted baselines/bridge — need a served OpenAI-compatible model.** Start one
(`python scripts/serve_qwen.py`) and point `Code/data/api/config.json` at it
(`{"api_key": "local", "base_url": "http://127.0.0.1:8765/v1"}`), then:

```bash
python scripts/llm_judge_gold.py          # LLM-judge (baseline C) on the gold
python scripts/baseline_majority_vote.py  # majority-vote (baseline B, K=5)
python scripts/baseline_beqplus.py        # BEq+ statement-level baseline
```

**(c) Aggregate + regenerate paper artifacts.**

```bash
python scripts/score_methods_vs_gold.py    # 5 methods × 4 checks → methods_vs_gold_result.json
python scripts/bootstrap_ci.py             # 95% bootstrap CIs
python scripts/make_tables.py              # → paper/results_tables.tex
bash   scripts/figures/make_all_figures.sh # → paper/figures/*.pdf
```

## Layout

- `instance_beq/` — the certifier: `config.py`, `artifacts.py`, `checks/`, `harness/` (Lean oracle +
  LLM wrapper), `baselines/`, `annotation/` (the 57-item gold + 5-annotator panel labels).
- `scripts/` — one script per experiment; `eval_logs/` holds their JSON outputs.
- `lean/InstanceBEq/` — Lean-side helpers (`SorryDetect`, `DefEq`, `Transfer`, `InstanceSound`).
- `paper/` — LaTeX source; tables and figures are auto-generated from `eval_logs/`.
- `docs/` — design doc, run guide, human-correlation protocol.
- `tests/` — mock fixtures + pytest suite (green with no Lean and no network).
- `Code/lean/` — **vendored** upstream Optlib + autoformalization examples (Apache-2.0, see
  `THIRD_PARTY.md`); the only non-original code, included so the symbolic experiments are turnkey.
  Point the `SITA_ROOT` env var at your own checkout instead if you prefer.

Instance-BEq is **read-only** over the autoformalizer's source tree: it reuses Lean invocation and
an LLM wrapper, never mutates the vendored files (planted variants are compiled in-memory), and runs
as a certification layer over final artifacts. Our contribution is everything outside `Code/`.
